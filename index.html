Système de Radar à Ultrasons à Courte Portée

Université de Béjaia | Abdelhakim BRAHMI | L2 Automatique

Présentation du projet : Le projet "Mini Radar" est un système de détection compact conçu pour repérer et cartographier des objets en temps réel. En utilisant des ondes ultrasonores, le système scanne une zone précise et analyse l'écho pour calculer la distance et la position des obstacles. Ces données sont ensuite affichées sur une interface graphique pour imiter le fonctionnement d'un radar industriel. Pourquoi ce projet ? Aujourd'hui, avec l'automatisation, il est essentiel que les machines puissent "voir" et se déplacer toutes seules. Les capteurs de contact physiques ne sont pas suffisants dans des environnements complexes ou rapides. La technologie radar offre une solution sans contact efficace pour détecter des obstacles, notamment pour les voitures autonomes ou la surveillance. Ce projet permet de comprendre comment ces principes complexes peuvent être appliqués avec du matériel simple et peu coûteux. Objectifs du projet : L'objectif principal est de construire un prototype de radar fonctionnel en utilisant un microcontrôleur et un capteur rotatif. Le système doit : Mesurer précisément la distance des objets entre 2 cm et 30 cm. Scanner l'environnement sur un angle de 180° grâce à un servomoteur. Afficher les résultats en temps réel sur un écran ou une interface logicielle.

Liste des composants :

  • Arduino Uno (Microcontrôleur)
  • Capteur Ultrason HC-SR04 (Détection)
  • Servomoteur MG90s (Rotation 360°)
  • Fils de connexion male-male & male-femelle
  • Breadboard
  • LEDs vertes et rouges
  • Buzzer actif
  • Resistances 220 Ohm

Logiciels utilisés

  • Arduino IDE : Environnement utilisé pour écrire et téléverser le code de contrôle du système.
  • Processing 4 : Logiciel utilisé pour créer l'Interface Graphique et visualiser les ondes du radar en temps réel.
  • Visual Studio Code : Éditeur utilisé pour le développement et la gestion du site web du projet.
  • Tinkercad : Logiciel utilisé pour dessiner le schéma du circuit électronique.

Spécifications techniques :

Portée 2cm - 30cm
Tension 5V
Angle de balayage 180°

Schéma détaillé montrant les connexions entre l'Arduino, le capteur, le servomoteur et le buzzer.

Guide des Couleurs

  • Fils Rouges : Alimentation positive (5V)
  • Fils Noirs : Masse (GND) pour fermer le circuit
  • Fil Bleu : Signal ECHO
  • Fil Marron : Signal TRIG
  • Fil Jaune : Signal Buzzer
  • Fils Verts : Signal LED
  • Fil Violet : Signal Servo Moteur

Le respect du code couleurs facilite le dépannage et évite les erreurs de court-circuit.
